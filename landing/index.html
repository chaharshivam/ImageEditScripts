Framewipe is a Mac app that runs on your machine. Use it to strip metadata from AI images and videos, split 2x2 grids into Instagram 4:5 and 9:16 frames, and clean clips — without sending files anywhere.

How to start Source

Who it is for

Creators who generate stills and clips, then need them Instagram-ready without a cloud uploader, an account, or a paid API.

What it does

  • Lossless metadata strip on JPEG, PNG, and WebP (pixels stay bit-identical).
  • Reads C2PA / Content Credentials and other origin declarations. It does not guess from pixels.
  • Splits 2x2 grids into 1080x1350 and 1080x1920 panels.
  • Cleans and scales video locally with ffmpeg.
  • Finds a burned-in watermark and either crops it out (safer) or paints it out.

SynthID in the pixels is not removed. Framewipe will tell you if a file declares it.

How to start

  1. Clone the repo onto your Mac (or copy the folder).
  2. Install ffmpeg: brew install ffmpeg.
  3. Double-click Framewipe.command. The first run creates a local .venv and opens your browser at 127.0.0.1.
git clone YOUR_GIT_REMOTE
cd ImageEditScripts
chmod +x Framewipe.command
open Framewipe.command

The processor always binds to 127.0.0.1. Do not put it on Fly, Render, or any public host — that would upload other people’s media to your server and cost money for ffmpeg.
